🔑 Authentication Token

Enter your JWT token to access protected endpoints:


📋 How to use:

  1. Paste your JWT token in the input field above
  2. Click "Set Token" to store it
  3. Click "Open Swagger UI" to access the API documentation
  4. In Swagger UI: Click the "Authorize" button (🔒) in the top right
  5. Authorization: Paste your token as "Bearer YOUR_TOKEN" and click "Authorize"
  6. Note: Remove "Bearer " prefix if it's already in your token
  7. Now you can test all protected endpoints!
